# 📱 마이링크 (MyLink) 메인 화면 와이어프레임 (Wireframe)

본 문서는 방문자 관점에서 경험하게 되는 **두 가지 핵심 메인 화면**의 레이아웃과 UI 컴포넌트 구조를 정의한 와이어프레임입니다:
1. **[화면 1] 방문자용 바이오 링크 공개 프로필 화면 (`/[username]`)** *(SNS 유입 시)*
2. **[화면 2] 서비스 소개 메인 랜딩 페이지 (`/`)** *(일반 웹 방문 시)*

---

### 🔍 주요 컴포넌트 상세 명세 (화면 1)
| 번호 | 컴포넌트 명 | 설명 및 인터랙션 |
|---|---|---|
| **1** | 아바타 & 상태 | 원형 이미지 또는 이니셜 텍스트. 우측 하단 녹색 점(`animate-pulse`)으로 활성 상태 표시 |
| **2~4** | 프로필 헤더 | 이름, 유저네임 뱃지, 감성적인 한 줄 소개 |
| **5** | 태그 칩 | 주요 관심사나 직무를 키워드 형태로 보여주는 미니 태그 |
| **6** | 링크 카드 리스트 | 마우스 오버(Hover) 시 살짝 떠오르는 스케일 업 애니메이션. 터치 시 새 창 열림 + 백그라운드 클릭 수 증가 |
| **7** | 퀵 소셜 아이콘 바 | 하단에 컴팩트하게 배치된 원형 소셜 채널 바로가기 버튼 |
| **8** | 바이럴 배너 | 방문자가 자연스럽게 자신의 링크트리를 만들 수 있도록 랜딩 페이지로 유도하는 CTA |

## 3. 모바일 화면 전환 흐름 (Interaction Flow)

```mermaid
sequenceDiagram
    autonumber
    actor V as 방문자 (Visitor)
    participant P as 프로필 페이지 (/[username])
    participant S as Zustand 스토어 (LocalStorage)
    participant T as 외부 대상 사이트 (Target URL)

    V->>P: SNS 링크 클릭하여 프로필 접속
    P->>S: 해당 유저의 프로필 및 링크 정보 조회
    P-->>V: 모던 글래스모피즘 테마 프로필 화면 렌더링
    
    opt 링크 카드 클릭 시
        V->>P: "GitHub" 카드 탭
        P->>S: incrementClick("github") 호출 (클릭 수 +1)
        P->>T: 새 탭에서 https://github.com/mlm577373 안전하게 오픈
    end

    opt 공유 버튼 클릭 시
        V->>P: 상단 [공유] 버튼 탭
        P-->>V: 클립보드 주소 복사 완료 토스트 표시 ("링크가 복사되었습니다!")
    end

    opt 하단 배너 클릭 시
        V->>P: "나만의 마이링크 만들기" 탭
        P-->>V: 랜딩 페이지(/) 또는 대시보드(/admin)로 이동
    end
```
