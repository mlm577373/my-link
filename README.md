# 🔗 마이링크 (MyLink)

> **나만의 링크와 프로필을 감각적으로 공유하는 바이오 링크 서비스**

![Next.js](https://img.shields.io/badge/Next.js-16-black?style=flat-square&logo=next.js)
![TypeScript](https://img.shields.io/badge/TypeScript-5-blue?style=flat-square&logo=typescript)
![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-v4-38bdf8?style=flat-square&logo=tailwindcss)

---

## ✨ 주요 특징
- 🎨 **모던 & 글래스모피즘 디자인**: 은은한 그라데이션과 부드러운 호버 인터랙션
- ⚡ **Next.js App Router**: 최신 표준 라우팅 및 초고속 렌더링
- 📱 **완벽한 반응형(Mobile-first)**: 스마트폰과 데스크톱 모두에 최적화
- 📋 **원클릭 프로필 공유**: 클립보드 링크 복사 지원

---

## 🚀 빠른 시작

```bash
# 패키지 설치
npm install

# 로컬 개발 서버 시작
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000)으로 접속하여 확인하세요.
